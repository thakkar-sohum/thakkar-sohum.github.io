# Qolour

Qolour is an interactive quantum computing device that brings quantum mechanics out of the lab and into the real world. This repository contains the website and documentation for the Qolour project.

## About

Qolour is pioneering the development of the first object outside of a laboratory environment that operates based on the fundamental laws of quantum mechanics. Our mission is to make quantum computing more accessible and visually engaging.

## Features

- Interactive quantum computing interface
- Beautiful visual representations of quantum states
- Responsive web design for all devices
- Modern, clean user interface

## Technologies Used

- HTML5
- CSS3 (Webflow CSS framework)
- JavaScript
- jQuery
- D3.js for visualizations
- Webflow for design and CMS

## Setup

1. Clone this repository
2. Open index.html in a modern web browser
3. No build process required - this is a static website
